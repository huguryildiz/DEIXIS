## Why

After B5 and B6 a research can be followed through nine API routes plus the schedule route, a scheduler checks interval watches while DEIXIS runs, and a closed or sleeping computer leaves stored gaps. None of it is visible: there is no screen, no count, no way to turn follow-up on, read what was found, dismiss it, change the schedule or learn that time went unchecked. B7 builds those screens on the existing routes and read models, with one small read-only backend addition (the sidebar count). It adds no new watch behavior. Everything it shows comes from stored backend state; it must never claim coverage the stored reads do not show.
