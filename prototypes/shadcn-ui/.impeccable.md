## Design Context
Users: researchers working locally with questions, papers, evidence and reports.
Tone: quiet, precise, readable. The user explicitly requested a simpler UI that does not tire the eyes.
Direction: shadcn foundation with the earlier research interactions integrated; premium but calm charcoal dark mode by default, soft ivory text and a restrained warm-metal accent. No green UI. Light mode remains a neutral alternative. Editorial heading, restrained navigation and progressive disclosure. English UI follows the agreed product brief.
Principles: question first; source evidence one click away; no invented research; accessible contrast and keyboard controls; retain existing project files.
Layout: use the full available main workspace width on desktop rather than a narrow centered page; keep long prose at a readable line length and preserve the mobile layout.
