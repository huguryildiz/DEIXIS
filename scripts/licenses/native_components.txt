Native components and tools listed by hand
==========================================

The scans above read Python and npm metadata only. These parts come with the packaged app or are named in it, and are
not covered by those scans. Their full licence and NOTICE texts are added when the packaged build is made (P10); this
list says which licences apply.

MuPDF (inside PyMuPDF)
  Artifex MuPDF, the PDF engine that PyMuPDF wraps and ships in its wheels. Dual-licensed: GNU AGPL-3.0 or an Artifex
  commercial licence. DEIXIS uses the AGPL-3.0 option and is itself AGPL-3.0-or-later. https://mupdf.com/

Tesseract OCR and its language data
  Tesseract OCR engine: Apache-2.0, with a NOTICE file that goes with any distribution that includes one.
  Tessdata language files (tessdata_fast and tessdata_best): Apache-2.0.
  The libraries a bundled Tesseract build links (for example Leptonica) carry their own permissive licences, listed from
  the build's actual contents. https://github.com/tesseract-ocr/tesseract

Tauri and the system web view (desktop shell)
  Tauri: MIT or Apache-2.0, as are most of the Rust crates it builds on; the crate list is generated from the shell's
  Cargo.lock at build time. https://tauri.app/
  The web view is the one the operating system provides: WKWebView on macOS, Microsoft Edge WebView2 on Windows,
  WebKitGTK (LGPL-2.1-or-later) on Linux. DEIXIS does not copy any of them into its own files.

Downloaded on request, not part of the package
  The model command-line tools you connect (Codex, Claude Code, Gemini CLI) are separate programs under their own terms.
