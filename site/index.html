Questions

Is DEIXIS free?
The app is open source under AGPL-3.0. You pay only for the model you connect, through your own subscription or API key. Scholarly search through OpenAlex needs no payment.
Where does my data go?
The app and your library stay on your Mac. Searches go to the scholarly sources you connect, and model steps go to the model you connect, each with only the input that step needs. Keys are kept in the macOS Keychain.
Does it check that a source supports the claim?
No. Code checks that every cited span exists in a passage the model was given. Whether the passage supports the sentence is for you to read, and each answer says so.
What happens when a full text cannot be found?
The source stays at abstract depth and is labelled that way. An abstract cannot support details it does not state. Missing full texts keep downloading in the background, and a late full text can lead to one revision of the answer, with the earlier answer kept.
Can I add my own PDFs?
Yes. Attach up to five seed PDFs to guide a search, or ask a question about PDFs you attach. A PDF citation opens the document on the cited page.
Why does macOS block the first launch?
The app is not signed with an Apple Developer ID yet. Open it once, then choose Open Anyway in System Settings → Privacy & Security.
