# Test map

This table covers the 17 test-bearing folders currently under `tests/`, the acceptance and fixture folders, and top-level support files. Responsibilities and invariants are summarized from file names, test names and docstrings; this is a navigation map, not a coverage audit or a record of passing tests. Synthetic cases and scripted adapters establish application behavior, not scientific validity, model quality or live-provider performance.

| Folder | What it guards | Notable invariants | Link to related decisions |
|---|---|---|---|
| [app/](app/) | API, worker and persistence integration; human queues, audit samples, PDF waiting lists and research views. | Late or cancelled results stay unapplied; selection changes mark answers stale; user decisions take precedence; queue writes reject changed row tokens; views avoid per-record library reads. | [D5], [D96], [D99], [D102] |
| [candidates/](candidates/) | Claim-candidate versions, decomposition, kill-search planning, stored matrices and API boundaries. | Idempotent replay stays scoped to the candidate and research; owner decisions remain separate from computed status; evidence uses frozen inputs and located quotes; no-match status does not establish novelty. | [D144], [D145], [D146], [D152] |
| [contracts/](contracts/) | Schemas, validation, citation handles, phrase frames, method-package integrity and deterministic decision rules. | Equivalent content hashes identically across ordering and processes; citations resolve to supplied passages; anchors remain source-owned; structural validity and package integrity do not establish semantic support. | [D12], [D27], [D70], [D71] |
| [discovery/](discovery/) | Vocabulary, protocol approval, paging, screening, ranking, chaining and full-text adjudication. | Search waits for user approval; quotes are verified on supplied pages; unread records stay distinct from exclusions; ranking does not itself exclude; protocol inputs and accounting remain recorded. | [D70], [D79], [D80], [D81], [D85] |
| [documents/](documents/) | PDF acquisition, version identity, extraction, OCR, equations, figures and semantic retrieval. | One PDF is in use per source version; replacement preserves historical passages; OCR is explicit and labelled; arXiv equations match the source version and page numbers; fetch and parser work remain bounded. | [D6], [D45], [D51], [D52], [D104] |
| [hardening/](hardening/) | Fault handling, child lifetimes, restore/upgrade guards, capacity tooling and measurement-driver accounting. | Torn files are not accepted as complete; disk failures retain typed reasons; restore preserves rows and files and refuses unsafe targets; matrix verdicts depend on recorded execution results. | [D162], [D163], [D164], [D166], [D170] |
| [lineage/](lineage/) | Development-line roles, mention candidates, graph assembly, link evidence, human edits and publication. | Citation edges alone create no candidate; link decisions and edits are append-only; graph rules reject cycles; evidence remains linked to supplied inputs; structural checks do not establish usefulness. | [D130], [D132], [D133], [D134], [D142] |
| [measurement/](measurement/) | Isolated search experiments and P4/P6 measurement tools. | Query lanes retain distinct provenance; experimental budgets and seed gates are explicit; stored counts and identities keep their denominators; offline tool checks do not measure retrieval or model quality. | [D8], [D64], [D141], [D202] |
| [models/](models/) | Model adapters, connection settings, embeddings, transport accounting and schema compatibility. | Selected model and effort are sent explicitly; missing or mismatched model identity is not verified; credentials stay out of the Codex environment; fresh outputs bind to the active attempt; requests and sends are counted separately. | [D5], [D7], [D172], [D199], [D204], [D211] |
| [process/](process/) | Real subprocess crash, restart, shutdown, backup/restore and child-ownership boundaries on test-owned libraries. | Interrupted writes do not publish partial files; a successor recovers held work; children end with their owner; watch restart remains bounded. Process-marked tests run only when `-m` names `process`. | [D162], [D163], [D187] |
| [providers/](providers/) | Scholarly connectors, query compilation, pagination, routing, DOI lookups and record linking. | Invalid or undeclared requests are refused before send; provider query syntax and budgets are preserved; search and lookup roles remain distinct; merges are undoable; mocked responses do not establish live access or recall. | [D44], [D72], [D87], [D174], [D193], [D194] |
| [reextract/](reextract/) | Extraction retry, stored-file repair, ownership, recovery history and historical citation views. | Explicit retries use hash-checked private copies and per-file locks; failed retries preserve the previous head; abandoned operations are reconciled without rerunning; old citations open their own extraction; history survives backup and authorized purge. | [D190], [D191], [D192], [D195], [D197] |
| [report/](report/) | Evidence tables, frozen report plans, section validation, assembly, review, edits, citation removal and exports. | Failed rows stay outside report evidence; cell and claim revisions preserve history; citation removal is reversible; repair is bounded and cannot silently lose claims; exports use the recorded read model and retain unchecked limits. | [D38], [D120], [D125], [D148], [D150], [D155], [D198] |
| [review/](review/) | User-requested answer, report and candidate review over immutable snapshots. | Findings do not silently edit their target; applying a finding uses the checked editor save; dependency changes mark reviews stale; quote mapping fails closed; snapshot files remain reachable through backup and protected from unrelated purge. | [D180], [D181], [D182], [D185] |
| [storage/](storage/) | Migrations, library sharing, trash, corpus removal, backup and stored legacy records. | Passage text and step inputs are immutable; migrations preserve rows and foreign keys; removed evidence stays reopenable; backup retains referenced files and trash; legacy records remain readable but cannot resume discovery. | [D6], [D45], [D50], [D119] |
| [watch/](watch/) | Follow-up identity, announcements, manual checks, scheduling, recovery and lifecycle separation. | Watches do not admit evidence or write library records; each new record is announced once; interrupted checks stay unpublished; scheduling is opt-in and uses bounded catch-up; counts distinguish surviving records from notices. | [D180], [D186], [D187], [D188] |
| [model_behavior/](model_behavior/) | JSON case catalogs for answer, report, lineage, candidate and review builders and runners. | Prepared cases and planted faults remain synthetic; model-free catalog checks do not establish actual model behavior or review quality. | [D123], [D140], [D154], [D184], [D189] |
| [acceptance/](acceptance/) | Fixture servers supporting browser acceptance in [apps/web/e2e/](../apps/web/e2e/). | The real application uses scripted model outputs, mocked OpenAlex and fixed PDFs; follow-up pages are synthetic; browser success establishes handling of these fixtures. | [D8], [D122], [D188] |
| [fixtures/](fixtures/) | Stored research inputs/outputs, connector baselines, search-page records and LaTeX/BibTeX goldens. | Replay inputs and byte-pinned exports remain reproducible; synthetic fixtures and golden equality do not establish scientific correctness or live API acceptance. | [D153], [D155], [D177], [D211] |
| Top-level helpers: [conftest.py](conftest.py), `*_helpers.py`, `*_baseline.py`, [determinism_stages.py](determinism_stages.py) | Shared test isolation, synthetic builders, explicitly captured baselines and cross-process replay stages. | Tests use an in-memory keychain and clear real model API keys; baseline regeneration is explicit; process tests require explicit selection; builders use synthetic or isolated libraries. | [D5], [D70], [D103], [D104], [D177], [D191] |
| Top-level fakes: [fakes.py](fakes.py), [fake_embedding_runner.py](fake_embedding_runner.py) | Scripted model and embedding stand-ins. | The test adapter is never registered by the live application; the fake embedding runner checks the protocol and manifest without loading fastembed; fake outputs do not establish model quality. | [D8], [D103] |
